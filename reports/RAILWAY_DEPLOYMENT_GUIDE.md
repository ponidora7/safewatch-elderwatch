# 🚀 Panduan Setup & Deployment SafeWatch di Railway

Dokumen ini menjelaskan langkah-langkah lengkap untuk melakukan setup dan deployment sistem SafeWatch ElderWatch di platform cloud **Railway**. Sistem ini terdiri dari dua komponen utama:
1. **Backend**: FastAPI Web API (`/backend`)
2. **Frontend**: Next.js Dashboard (`/frontend`)

---

## 📋 Persyaratan Awal (Prerequisites)

Sebelum memulai, pastikan Anda telah menyiapkan akun dan resource berikut:
1. **GitHub Account & Repository**: Project SafeWatch Anda harus sudah di-push ke GitHub. 
2. **Railway Account**: Daftar di [railway.app](https://railway.app) dan hubungkan dengan akun GitHub Anda.
3. **Supabase Project**: Database PostgreSQL cloud gratis untuk menyimpan riwayat insiden dan sinkronisasi real-time.
4. **Resend Account**: Layanan pengiriman email untuk notifikasi darurat. Daftar gratis di [resend.com](https://resend.com) untuk mendapatkan API Key.
5. **Hugging Face Account** (Opsional): Jika Anda menggunakan model deteksi AI eksternal yang di-host di Hugging Face Spaces/Inference API.

---

## 🗄️ Langkah 1: Setup Supabase Database

Aplikasi SafeWatch membutuhkan tabel bernama `incidents` di Supabase untuk mencatat kejadian jatuhnya lansia (fall detection).

1. Buka **Dashboard Supabase** Anda dan masuk ke menu **SQL Editor**.
2. Jalankan perintah SQL berikut untuk membuat tabel `incidents`:

   ```sql
   create table public.incidents (
       id bigint generated by default as identity primary key,
       type text not null,
       confidence double precision not null,
       inference_ms integer not null,
       created_at timestamp with time zone default timezone('utc'::text, now()) not null
   );
   ```

3. **PENTING: Aktifkan Fitur Realtime**
   Agar dashboard frontend dapat menampilkan notifikasi instan secara real-time tanpa harus me-refresh halaman:
   - Di dashboard Supabase, buka menu **Database** -> **Replication**.
   - Pada bagian **supabase_realtime**, klik **Source** (atau tables).
   - Aktifkan toggle untuk tabel `incidents`.

## 🐍 Langkah 2: Deploy Backend (FastAPI) di Railway

Layanan backend menangani pemrosesan frame gambar, pemanggilan model AI (Hugging Face), penyimpanan log ke Supabase, dan pengiriman notifikasi email via Resend.

1. Buka dashboard Railway dan klik **New Project** -> **Deploy from GitHub repo**.
2. Pilih repositori SafeWatch Anda.
3. Setelah service dibuat, klik pada service tersebut dan buka tab **Settings** untuk mengonfigurasinya:
   - **Service Name**: Ubah nama service menjadi `safewatch-backend`.
   - **Root Directory**: Isi dengan `backend`. (Ini mengarahkan Railway untuk hanya mem-build folder backend).
4. Masuk ke tab **Variables** dan tambahkan environment variables berikut:

   | Variable | Value |
   |---|---|
   | `SUPABASE_URL` | `https://<your-project-id>.supabase.co` |
   | `SUPABASE_KEY` | `<your-supabase-anon-key>` |
   | `RESEND_API_KEY` | `<your-resend-api-key>` |
   | `EMAIL_FROM` | `onboarding@resend.dev` |
   | `EMAIL_TO` | `recipient@example.com` (Ubah ke email tujuan penerima notifikasi) |
   | `NOTIFICATION_COOLDOWN` | `5` |
   | `HF_API_URL` | `https://api-inference.huggingface.co/models/<your-hf-username>/<your-model-name>` |
   | `HF_TOKEN` | `<your-huggingface-read-token>` |
   | `CONFIDENCE_THRESHOLD` | `0.7` |

5. Buka tab **Settings** -> **Networking** -> Klik **Generate Domain** untuk membuat URL publik untuk backend Anda. 
   - Salin URL ini (contoh: `https://safewatch-backend-production.up.railway.app`). Anda akan membutuhkannya untuk konfigurasi Frontend.

## 💻 Langkah 3: Deploy Frontend (Next.js) di Railway

Dashboard frontend Next.js menerima video stream dari webcam lokal (klien), mengirimkan frame ke API backend, dan berlangganan ke Supabase Realtime untuk memantau insiden terbaru secara langsung.

1. Di project Railway yang sama, klik tombol **New** (kanan atas) -> **GitHub Repo**.
2. Pilih repositori SafeWatch yang sama.
3. Setelah service baru dibuat, buka tab **Settings**:
   - **Service Name**: Ubah nama service menjadi `safewatch-frontend`.
   - **Root Directory**: Isi dengan `frontend`.
4. Masuk ke tab **Variables** dan tambahkan environment variables berikut:

   | Variable | Value / Deskripsi |
   |---|---|
   | `NEXT_PUBLIC_SUPABASE_URL` | URL Supabase Anda (Sama dengan backend) |
   | `NEXT_PUBLIC_SUPABASE_KEY` | Anon Key Supabase Anda (Sama dengan backend) |
   | `NEXT_PUBLIC_API_URL` | **URL Publik Backend** yang Anda salin dari Langkah 2 (Contoh: `https://safewatch-backend-production.up.railway.app`) |

5. Buka tab **Settings** -> **Networking** -> Klik **Generate Domain** untuk mendapatkan alamat URL dashboard Anda.

## 🔒 Konfigurasi CORS (Cross-Origin Resource Sharing)

Secara default, backend FastAPI telah dikonfigurasi untuk menerima semua origin (`allow_origins=["*"]` di [backend/main.py](file:///d:/safewatch-elderwatch/backend/main.py)), sehingga frontend Next.js dapat melakukan request API tanpa mengalami kendala CORS.

## 🛠️ Troubleshooting & Tips Tambahan

* **Error: Port Binding**: Railway menetapkan port dinamis melalui env variable `PORT`. Kami telah memperbarui [backend/main.py](file:///d:/safewatch-elderwatch/backend/main.py) agar dapat mendeteksi port ini secara otomatis:
  ```python
  port = int(os.environ.get("PORT", 8000))
  ```
* **Git Whitelisting**: Folder `frontend/src/lib` sebelumnya diabaikan oleh `.gitignore` utama. Kami telah menambahkan pengecualian (`!frontend/src/lib/`) ke [.gitignore](file:///d:/safewatch-elderwatch/.gitignore) dan mengunggah client Supabase [frontend/src/lib/supabase.ts](file:///d:/safewatch-elderwatch/frontend/src/lib/supabase.ts) agar tidak tertinggal saat di-push ke GitHub.
* **Memeriksa Log**: Jika aplikasi gagal dijalankan (crash), buka tab **Logs** di masing-masing service di Railway untuk melihat error detail dari terminal.
