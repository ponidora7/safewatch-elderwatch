# 🛠️ Panduan Setup Supabase & Hugging Face - SafeWatch

Dokumen ini menjelaskan langkah-langkah lengkap untuk melakukan konfigurasi **Supabase** (sebagai database real-time) dan **Hugging Face** (jika ingin menggunakan model klasifikasi gambar/deteksi objek berbasis cloud).

---

## 🗄️ 1. Setup Supabase (Database & Real-time Alerts)

Supabase digunakan untuk mencatat riwayat insiden secara permanen dan menyinkronkan notifikasi darurat secara real-time ke Next.js Dashboard.

### Langkah A: Membuat Project Baru
1. Buka [Supabase Dashboard](https://supabase.com) dan login/daftar akun.
2. Klik tombol **New Project** dan pilih organisasi Anda.
3. Isi informasi project:
   - **Name**: `SafeWatch-ElderWatch`
   - **Database Password**: Buat password yang kuat (simpan password ini).
   - **Region**: Pilih wilayah terdekat dengan pengguna/server Anda (misalnya: *Singapore* untuk Asia Tenggara).
4. Klik **Create new project** dan tunggu proses inisialisasi selesai (sekitar 1-2 menit).

### Langkah B: Membuat Tabel `incidents`
1. Di panel kiri dashboard Supabase, buka menu **SQL Editor** (ikon lembar kertas dengan tanda `SQL`).
2. Klik **New Query**.
3. Tempelkan perintah SQL berikut ke dalam editor:
   ```sql
   -- Membuat tabel incidents untuk mencatat setiap deteksi jatuh/kebakaran
   create table public.incidents (
       id bigint generated by default as identity primary key,
       type text not null,
       confidence double precision not null,
       inference_ms integer not null,
       created_at timestamp with time zone default timezone('utc'::text, now()) not null
   );
   ```
4. Klik tombol **Run** (atau tekan `Ctrl + Enter`). Pastikan output menunjukkan sukses.

### Langkah C: Mengaktifkan Fitur Real-time (Sangat Penting! 🚨)
Agar Next.js Dashboard dapat menerima notifikasi secara instan tanpa perlu memuat ulang halaman (*refresh*), Anda harus mengaktifkan sistem replikasi Real-time pada tabel `incidents`:
1. Di dashboard Supabase, buka menu **Database** -> **Replication** (di bagian bawah panel kiri).
2. Di tabel daftar replikasi, cari baris bernama **supabase_realtime** (biasanya di bawah sub-menu *Replication* atau di tab *Publications*).
3. Klik tombol **Source** atau **Tables** pada replikasi tersebut.
4. Cari tabel `incidents` dan aktifkan toggle/centang tabel tersebut untuk memasukkannya ke publikasi real-time.

### Langkah D: Mengambil API Credentials
1. Buka menu **Project Settings** (ikon gerigi di kiri bawah) -> **API**.
2. Salin nilai berikut untuk digunakan pada `.env` Anda:
   - **Project URL**: Ini akan menjadi `SUPABASE_URL` (contoh: `https://xyz.supabase.co`).
   - **API Key (anon public)**: Ini akan menjadi `SUPABASE_KEY` (key publik anonim).

---

## 🤗 2. Setup Hugging Face (Inference API)

Jika Anda ingin menggunakan model deteksi AI yang di-host di cloud Hugging Face (misalnya sebagai fallback klasifikasi gambar), lakukan setup berikut.

### Langkah A: Membuat Akun & Token Akses
1. Buka [Hugging Face](https://huggingface.co) dan masuk/buat akun baru.
2. Klik ikon profil Anda di kanan atas -> **Settings** -> **Access Tokens**.
3. Klik tombol **New Token**.
4. Isi detail token:
   - **Name**: `SafeWatch-API`
   - **Role**: Pilih **Read** (sudah cukup untuk melakukan inferensi).
5. Klik **Generate a token** dan salin token tersebut. Ini akan digunakan sebagai `HF_TOKEN`.

### Langkah B: Menentukan Model Endpoint (`HF_API_URL`)
Hugging Face menawarkan ribuan model gratis yang bisa digunakan langsung via **Inference API** tanpa perlu men-deploy server GPU sendiri.
1. Cari model klasifikasi gambar jatuh yang relevan di Hugging Face (misalnya model Vision Transformer atau YOLOv8-Classification yang dipublikasikan komunitas).
2. Struktur URL API Hugging Face adalah sebagai berikut:
   ```text
   https://api-inference.huggingface.co/models/<username-pemilik>/<nama-model>
   ```
   *Contoh jika menggunakan model klasifikasi umum:*
   ```text
   https://api-inference.huggingface.co/models/google/vit-base-patch16-224
   ```
3. Set URL ini ke dalam environment variable `HF_API_URL`.

---

## ⚙️ 3. Konfigurasi Environment Variables (`.env`)

Setelah mendapatkan kredensial dari langkah-langkah di atas, tambahkan/ubah nilai tersebut pada file `.env` di direktori proyek Anda:

```env
# Supabase Credentials (dari Langkah 1.D)
SUPABASE_URL=https://your-project-id.supabase.co
SUPABASE_KEY=your-supabase-anon-key

# Hugging Face Credentials (dari Langkah 2)
HF_API_URL=https://api-inference.huggingface.co/models/google/vit-base-patch16-224
HF_TOKEN=hf_your_token_value_here
```

Dengan konfigurasi ini, database Supabase siap mencatat riwayat insiden dan mengalirkan event notifikasi secara real-time ke antarmuka dashboard Next.js!
